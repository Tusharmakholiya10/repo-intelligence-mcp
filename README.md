# RepoMind

AI-powered codebase intelligence MCP server for AI coding agents.

## Current Features

- MCP server built with Python
- MCP tool discovery
- Repository file listing
- MCP client for testing
- Tool execution through MCP protocol

## Architecture

AI Agent
    ↓
MCP Client
    ↓
RepoMind MCP Server
    ↓
Repository Intelligence Tools
    ↓
Git Repository

## Tech Stack

- Python
- MCP
- FastMCP
- pytest
